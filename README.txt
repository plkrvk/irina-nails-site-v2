Второй вариант сайта в стиле editorial / luxury beauty.

Файлы:
- index.html — структура страницы;
- style.css — стили, адаптивность и анимации;
- script.js — интерактив и scroll-анимации;
- assets/oblozhka.png — предоставленная фотография.

Обновление:
- Кнопка «записаться» в шапке получила тёмный полупрозрачный фон, blur-эффект и контрастную обводку, чтобы белый текст не терялся на светлой фотографии.
- HTML и CSS отформатированы многострочно для удобной работы верстальщика.
